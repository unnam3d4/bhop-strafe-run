# BHOP: STRAFE RUN

Оригинальный HTML5/WebGL bunny-hop time-trial для Яндекс Игр.

## Управление
- WASD — движение
- Мышь — обзор
- SPACE — bunny hop
- R — быстрый рестарт
- P / ESC — пауза
- На телефоне: левый стик, свайп справа и JUMP

## Статус
Первый уровень настроен как обучающий: широкие платформы, короткие разрывы и более прощающий air-strafe.

## Технологии
- HTML5 / CSS / JavaScript
- WebGL без внешних игровых библиотек
- Yandex Games SDK с локальным fallback

## План
Довести проект до production-ready состояния для Яндекс Игр: уровни, меню, сохранения, реклама, лидерборды, мобильная адаптация, тестирование и релиз.
